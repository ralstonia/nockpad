# Nockpad Quiet 0.3.0 — by Codex

One persistent intention, an optional central countdown, short duration presets, and silent defaults.

Experimental edition designed and implemented by Codex at Ram’s invitation. These are independent editions, not cumulative upgrades. Choose the
one that fits you. [Compare all five editions](https://github.com/ralstonia/nockpad/blob/main/EDITIONS.md).

## Install

macOS 14 or later. The ZIP contains Apple Silicon and Intel architectures. Unzip
and move the app to Applications. Each edition has separate local data and can
coexist with the others. No personal notes, tasks, settings, or private Git history
are included.

**Ad-hoc signed and not Apple-notarized.** macOS may block the first launch. Review
[Apple's guidance](https://support.apple.com/102445) before deciding whether to allow
it. There is no paid Apple certificate or App Store listing.

Download the ZIP and its `.sha256` file into the same folder, then verify:

```sh
shasum -a 256 -c Nockpad-0.3.0-quiet-universal-macOS.sha256
```

Universal Release build, archive integrity, extracted code signature, checksum,
and automated behavior checks were verified. Intel hardware, every supported macOS
version, and the new experimental screens have not completed interactive testing.
A possible disappearance was reported in personal use; no matching crash report
was found. Back up valuable notes and tasks.
